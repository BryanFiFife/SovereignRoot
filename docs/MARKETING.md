# SovereignRoot launch kit

## One-line positioning

**Your rules above the AI.** SovereignRoot lets anyone create a portable, signed `sovereignty.json` defining the boundaries compatible AI agents must never cross.

## Short pitch

AI authorization systems decide what an agent *may* do. SovereignRoot defines what it may **never** do — no matter which model, vendor, task token, prompt or child agent is involved. Users answer plain-English questions, generate a cryptographically signed policy locally in the browser, and keep ownership of the root identity themselves.

## Non-negotiable marketing language

Use:

- “signed root policy”
- “portable constraint document”
- “vendor-neutral”
- “local-first”
- “requires compatible runtime enforcement”
- “working specification”

Do not claim:

- that the JSON forces every AI provider to comply;
- that prompt-only use is hard enforcement;
- that SovereignRoot is an IETF/W3C/NIST standard;
- that the product makes agents unhackable or guarantees safety;
- that the exact concept has no prior art.

## Suggested launch headline

**We keep giving AI agents more permission. I built the file that tells them where permission ends.**

## Suggested subheading

Generate your own signed `sovereignty.json` — free, private, local-first and designed to survive the model or platform you use today.
